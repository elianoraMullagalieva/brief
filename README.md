# Клиентский бриф

Пошаговая анкета на 7 этапов с отправкой в Telegram.
Адаптирована под телефон, планшет и широкие экраны.

---

## Что внутри

| Файл | Зачем |
|---|---|
| `index.html` | Разметка страницы |
| `styles.css` | Оформление |
| `app.js` | Логика: этапы, валидация, черновик, файлы |
| `config.js` | **Единственный файл для правки** — адрес приёмника |
| `worker.js` | Код для Cloudflare — не нужен на сайте, только скопировать |
| `assets/` | Фото и логотип |

---

## Публикация на GitHub Pages

1. Создать репозиторий, например `brief`
2. Загрузить туда все файлы **кроме** `worker.js` (он живёт в Cloudflare)
3. **Settings → Pages → Source: Deploy from a branch → main → / (root)**
4. Через минуту сайт откроется по адресу
   `https://<логин>.github.io/brief/`

## Подключение Telegram

### 1. Бот

@BotFather → `/newbot` → имя → username на `bot` → получите **токен**.

Токен — это пароль. Он хранится только в Cloudflare и никогда не попадает в код сайта.

### 2. CHAT_ID

Напишите боту любое слово, затем откройте:

```
https://api.telegram.org/bot<ТОКЕН>/getUpdates
```

Найдите `"chat":{"id":123456789` — это ваш CHAT_ID.

Для группы: добавьте бота в группу, дайте админку, напишите в неё — id будет с минусом.

### 3. Cloudflare Worker

1. [dash.cloudflare.com](https://dash.cloudflare.com) → **Workers & Pages** → **Create Worker**
2. Имя `brief-bot` → **Deploy** → **Edit code**
3. Вставить содержимое `worker.js` → **Deploy**
4. **Settings → Variables and Secrets**:

| Тип | Имя | Значение |
|---|---|---|
| Secret | `BOT_TOKEN` | токен бота |
| Secret | `CHAT_ID` | ваш id |
| Text | `ALLOWED_ORIGIN` | `https://<логин>.github.io` |

5. **Deploy**

### 4. Связать

В `config.js`:

```js
ENDPOINT: 'https://brief-bot.<логин>.workers.dev',
```

## Что придёт в Telegram

1. **Короткая сводка** — имя, контакт, зачем сайт, целевое действие, где рвутся сделки
2. **Файл `brief-….txt`** — все ответы целиком (обходит лимит Telegram в 4096 символов)
3. **Приложенные файлы** — каждый отдельным сообщением

---

## Пока ENDPOINT пустой

Форма работает полностью, но вместо отправки предлагает скачать файл с ответами.
Ничего не теряется — удобно тестировать до настройки бота.

## Как изменить вопросы

Все вопросы — в начале `app.js`, массив `STEPS`. Каждый вопрос:

```js
{ id:'b1',                    // уникальный, латиницей
  label:'Текст вопроса',
  hint:'Подсказка под вопросом',   // необязательно
  required:true,              // обязательное поле
  key:true,                   // плашка «важно»
  type:'text' }               // 'text' — одна строка, по умолчанию — многострочное
```

Порядок в массиве = порядок на сайте. Этапов может быть любое количество —
счётчик и точки пересчитаются сами.

---

## Ограничения файлов

10 файлов, каждый до 18 МБ (лимит Telegram — 20 МБ, оставлен запас).
Меняются в `app.js`: `MAX_FILES`, `MAX_FILE_SIZE`.

---

## Черновик

Ответы сохраняются в браузере посетителя (`localStorage`) и восстанавливаются
при возврате. После успешной отправки — очищаются.
